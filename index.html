zaentrum schemas

Published contracts for the zaentrum media platform. Every schema URL below is its own $id, is served as JSON, and is stable for its major version. Library v1 is the exception: it is a draft until a platform service adopts it, and its changes are listed in the repository README.

Library storage — v1

JSON Schema (draft 2020-12) for the on-storage library, where storage is the source of truth and databases are caches rebuilt from it. Every item is a folder holding manifest.json and metadata/metadata.json.

manifest.schema.jsonThe entry point of a movie, series or episode: identity, reference ids, playback fields, and every version with what its original contained and what its package lost.
metadata.schema.jsonEvery text and image of an item. The images sit next to it in metadata/.
defs.schema.jsonShared definitions.

Validate a tree with python tools/validate-library.py <dir> from the repository. The format is described in the wiki.
